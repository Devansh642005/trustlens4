# TrustLens – Digital Trust & Online Safety Web App

TrustLens is a Node.js + Express based web application that helps users
analyze suspicious messages and links to identify potential online threats.

## Tech Stack
- HTML, CSS, JavaScript
- Node.js
- Express.js
